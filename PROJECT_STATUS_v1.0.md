## 1. ОБЩАЯ ИНФОРМАЦИЯ О ПРОЕКТЕ

### 1.1. Название проекта
**ITAM System** - IT Asset Management System

### 1.2. Описание
Корпоративная система управления ИТ-активами с поддержкой:
- Централизованного учета активов
- QR-кодирования и мобильного доступа
- Управления жизненным циклом активов
- Двухэтапного согласования перемещений (МОЛ)
- Инвентаризации
- Интеграции с внешними системами
- Отчетности и аналитики

### 1.3. Технологический стек
- **Backend**: Python 3.10+, Flask
- **Database**: PostgreSQL 14+
- **ORM**: SQLAlchemy
- **Migrations**: Alembic
- **Frontend**: Jinja2, HTML/CSS/JS
- **QR**: qrcode, Pillow
- **PDF**: reportlab
